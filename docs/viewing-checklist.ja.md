## 既存前提と出発前の確認

既存の流れはPolycam＋スマホ写真→GLB・m単位YAML→AIでPNG/SVG/PDFの寸法付き間取り。
スキャン由来の寸法は概算です。端末機種・LiDAR有無・アプリ版・プラン・export権限は未確認です。

確認事項は一つにまとめて、**使う端末/アプリ版、LiDAR有無、現在のアカウントで
保存・export・オフライン動作の事前テスト結果、撮影/スキャン許可**。
未確定でも写真＋手測りで完遂できます。新しい有料アプリ・契約は不要です。

## 公開用テンプレートとprivateデータ

このGitHubは公開です。ここには汎用手順と空欄テンプレートだけを置きます。
実測値・実際の間取り・3D・写真・動画・住所・部屋番号・許可メモは、
**このGit checkoutの外**のprivateフォルダに保存し、アクセス制限した保存先または
既存private repoへバックアップします。公開Polycamリンクを作らないでください。
撮影許可と公開許可は別です。

private構成例：`home2/2026-10-04/{originals,exports,photos,notes,outputs}/`。
原本を保持し、加工・匿名化版は別保存。名前のない間取りや窓外の景色でも特定につながります。
別途公開が承認された場合も、人/鏡への映り込み、私物、書類、鍵、ラベル、ファイル名、
EXIF/位置情報、形状を点検します。既存home1の公開はhome2公開の許可を意味しません。

- [ ] 全室のつながりの略図、方角、部屋/壁/開口/設備ID。
- [ ] 搬入口から設置位置までの最小有効幅・高さ、曲がり角、エレベーター。
- [ ] 家具を置く有効壁長、冷蔵庫/洗濯機置場、重要な開口寸法と測定端点が分かる写真。
- [ ] 全室の縦横、天井/低い梁、全壁/凹凸、扉窓、柱、段差。
- [ ] 全壁、全電源/LAN/TV/エアコン等の位置、家電の接続部の写真。

順番：許可/略図→搬入→各室の実測/写真→任意スキャン→全室見直し/保存検証。

## ID・単位・基準点

室`R01`、時計回りの壁区間`R01-W01`、扉`R01-D01`、窓`R01-N01`、設備`R01-U01`、
寸法`M001`、写真`P001`、搬入区間`T01`。室名対応表をprivate略図に記載。
凹凸で壁を分け、壁の始点を明記。共通開口は両室から同じIDを参照します。

各室の床の測れる角を原点Oとし、最初の壁沿いを+X、室内への直角方向を+Y、上を+Z。
原点写真・軸矢印・室間の原点関係を略図に記録。別々のスキャンの座標が一致するとは限りません。
おおよその北と確認方法（方位計/仲介/図面）も記載し、スキャン軸から北を推定しない。

YAMLは**m**。紙にmmで書くなら単位を付けて一度だけ変換（800mm→0.800m）。
仕上げ面の測定端点、方法、繰返し値、誤差見込み、写真IDを残し、実測と推定を分離。
`null`は不明であり0ではありません。設備は指定した壁始点からの距離＋床からの高さで位置を記録。
その他は座標または壁からの距離。スキャンと略図の対応も記録します。

## 室ごとの実測

| 対象 | 現地で測るもの |
|---|---|
| 形状 | 全壁区間/凹み、縦横2方向、測れる対角、数か所の天井高、巾木の出。高さで形が変わる場合は家具高さでも測る。隠れた範囲を注記。 |
| 梁/柱/段差 | 幅/奥行/位置、梁下面高さと最小頭上余裕、柱の床占有範囲、床高差/敷居。 |
| 扉 | 実際に開けられる状態の有効幅/高さ（枠外寸ではない）、蝶番側、開閉軌跡、ノブ/戸当り、引戸の移動範囲/レール、敷居。許可を得てスキャン外で開閉確認。 |
| 窓/カーテン | 開口/枠の幅高さ、床から窓下端、壁角からの位置、開き方/軌跡、レール有効長/高さ/壁からの距離、シングル/ダブル/金具、カーテン丈の基準。 |
| 収納 | 入口と内部の有効幅/奥行/高さ、棚/パイプ位置、扉移動、固定物や配管で使えない部分。 |
| 家具 | 障害物のない壁長/奥行、椅子を引く空間、通路、扉/引出しの開閉。ベッド/机/ピアノ/本棚/ソファ/テーブルと比較。希望する余白は個人条件として明記。 |
| 冷蔵庫 | 最小有効幅/奥行/高さ、巾木/梁、蝶番と全開スペース、機種指定の放熱/保守余白、電源/アース。 |
| 洗濯機 | 防水パン外寸と有効内寸、支持部高さ、排水口中心位置/形、蛇口高さ/突出、ホース経路/上部空間、電源/アース、蓋/扉開閉と保守空間。 |
| キッチン/家電 | 天板高さ、下部スペース、フード/吊戸棚までの距離、見える給排水、家電位置/電源。接続を外さない。 |

**すべて**のコンセント/スイッチ/LAN/TV/照明/回線端末は、ID、室/壁、壁始点からの距離、
床からの高さ、口数、見えるラベル/端子形状/アース、接写を記録。LAN型の端子だけで開通済みと判断しない。
事業者・終端・工事許可を聞き、机/ルーター/TVの配線とドア横断を略図に追加。通路を確保します。

エアコンは既設寸法/位置/高さ、専用電源の表示電圧（表示・確認がなければ不明）、配管穴位置/測れる径、
取付可能空間、ドレン経路、室外機位置と設置制限を確認。写真から電気容量を推測したり配線を試験せず、
仲介/施工者へ未確認事項を引継ぎ。給排水の観察のみとし、バルブ操作は許可がある場合だけ。

## 搬入：荷下ろしから設置場所まで

- [ ] 荷下ろし→建物入口→EV/階段→共用廊下→玄関→室内廊下→各設置室の順に追う。
- [ ] 各開口の最小**有効**幅/高さ、開き限界、段差、ノブ、ドアクローザー、手すりなどの出っ張り。
- [ ] 曲がり角は進入/退出幅、曲がるための有効長方形/踊り場、頭上制限を測って略図。
  最小幅一つだけでは長い梱包が曲がれるか分からない。
- [ ] EV入口有効幅/高さ、かご有効幅/奥行/高さ、必要なら対角、積載表示、乗場寸法。
  EV不可なら階段の有効幅/踊り場/曲がり/最低頭上高さ。
- [ ] 予約、搬入時間、養生、荷下ろし制限、配送業者の下見を聞く。勝手に扉等を外さない。
  梱包寸法/重量/向き/回転と比較し、余裕が小さい場合は業者の最終確認が必要。

## 写真・任意スキャン

- [ ] 各室：入口全景、各壁正面（角/床/天井境界も）、逆方向全景、天井/梁、床/段差の詳細。
  大きい室は重なる写真と斜め写真でつながりを示す。
- [ ] 各設備：位置が分かる引き→接写→同じ面の読めるメジャー。端点メモを付ける。
  遠近のある写真だけで寸法を決めない。超広角だけに頼らず、ブレ/反射/白飛びは再撮影。
- [ ] 例：`R01_W01_overview_P001.jpg`、`R01_D01_clear-width_M001_P002.jpg`。
  写真台帳で原ファイル名→写真/設備/寸法ID、向き、説明を対応。後でコピーを改名してよく、原本はprivateに保持。
- [ ] 扉窓の閉/開は別写真、スキャン時の状態も記録。人/映り込み、書類、識別ラベル、外の景色を避ける。
  共用部は許可範囲のみ。スキャン中に扉や物を動かさない。
- [ ] 各室を出る前に壁/開口/天井/床/収納/設備/家電のIDとカメラロールを照合。欠落をその場でメモ。

| 実機テスト結果 | 方法 |
|---|---|
| LiDARあり・Polycam Space成功 | 必要な扉を先に開け固定。均一な照明でゆっくり動き、床〜天井/つながりを含める。欠け/反射/ドリフト確認。全室スキャンが失敗すれば室ごとの短いスキャンと位置関係のメモ。 |
| LiDARなし・対応Space成功 | 公式では現在iOS/機種制限あり。テスト済み端末内処理、模様のある角/特徴、重なる視点を使う。LiDARと同じ間取り成果物が出ると断定しない。 |
| 非対応/不明/export不可/失敗 | スマホの引き/接写＋手測り＋寸法入り略図で完遂。許可済み動画は補助。フォトグラメトリは事前テスト済みの場合だけ任意。 |

追跡が崩れたら失敗箇所を記録し小範囲で再撮影。鏡/ガラス、無地壁、隠れた端部は実測で補完。
既存端末と軽い処理を使い、現地作業にGPUサービスや重い再構築は不要です。

## スキャン補正・家具が入るかの判断

各室で異なる水平2方向＋高さ1つ、さらに購入/搬入の重要寸法を実測。
写真とモデルの同じ端点を対応させ、scan ID/値、手測り値、符号付き差`scan - manual`、相対差を記録。
怪しいメジャー/レーザーの値は繰り返します。

原モデルは上書きしません。基準寸法の比率が揃う場合のみ、派生モデルの一様scale補正を検討し、
係数/単位/変換/補正前後の照合を記録。方向ごとに違うなら局所歪み/ドリフトを疑い、再スキャンか実測形状を使用。
残る余白が誤差見込みと同程度なら再実測・業者確認を行い、「入る」と断定しない。
PolycamやAI間取りに固定の精度保証を置きません。

## 帰宅前の検証・保存・バックアップ

- [ ] 全室/設備/搬入IDと写真/メモを照合。必須値に単位/端点/方法/証拠、または欠落理由がある。
- [ ] 重要写真を拡大し目盛りを確認。モデルの室抜け、床/天井欠け、接続崩れ、二重壁、向きを点検。
- [ ] アプリ元capture/取得できるrawと未編集写真を保持。使えるならGLB、なければGLTFと
  **全`.bin`/texture付属ファイル**（exportがZIPならZIPも）を保存。OBJは材質/textureも。
  点群/アプリ間取りexportは既存権限で使える場合だけ任意。meshはrawの代わりではない。
- [ ] 可能ならexportを別viewerで開き、texture/単位/軸/基準寸法を確認。メモと原写真も再度開く。
  ファイル名/サイズ、端末/アプリ版/モード/export状況をprivate台帳に記録。
- [ ] privateな第2コピーを作り、件数/サイズ/サンプルを開いて照合。現地で転送できなければ
  端末保存を確認し「backup未完」と記録、帰宅直後に実施。検証まで削除/初期化/アンインストールしない。
  公開リンクはバックアップにしない。
- [ ] 不足寸法の再訪/確認方法を聞き、扉/照明/物を合意した状態に戻す。

帰宅後はprivateのYAMLを記入し、家具/機種別家電条件と照合、測定根拠・誤差付きのprivate間取り/配置案を作る。
公開テンプレは空欄のまま。搬入/回線/楽器/騒音の規約や見えた漏水/カビなども確認。
一度の内見で終日の日当たりや騒音を判断しません。

## 公式参照

2026-10-03（JST）確認。実際の端末/アカウントのテストを優先し、メーカー記述を精度保証とは扱いません。

- [プラン](https://poly.cam/pricing)：Freeのリンク共有はpublicと記載。新しい契約なしで端末export/private保存を使う。
