# 今後できること

今回の検証では、Polycam の3Dスキャンと室内写真を基に、現在の部屋を構造化し、概略間取り図と寸法付き間取り図を作成した。

ここから先は、引っ越しや新居入居時のデータ収集と組み合わせることで、以下の用途に発展できる。

## 1. 家具・家電台帳

家具名、幅・奥行・高さ、重量、分解可否、現在位置、持っていく/処分/買い替えを整理する。

これにより、新居スキャンと突き合わせて、家具配置や搬入可否を自動判定しやすくなる。

## 2. 設備・コンセント・通信端子マップ

以下を位置情報付きで記録する。

- 電源コンセント
- LAN端子
- TV端子
- ONU / ルーター候補位置
- エアコン
- 照明
- スイッチ
- 給湯・換気設備

家具配置だけでなく、在宅勤務環境、Wi-Fi、有線LAN、スマートホーム設計にも利用できる。

## 3. 搬出入経路図

- 玄関有効幅
- 共用廊下幅
- 室内廊下幅
- 各ドア有効幅
- 曲がり角
- エレベーター扉幅・内部寸法

大型家具や家電が搬出・搬入できるかを事前に判定する。

## 4. 動線・空きスペース分析

家具配置から以下を可視化する。

- 人の通路幅
- デッドスペース
- 椅子の可動範囲
- ベッド周辺クリアランス
- ロボット掃除機の走行可能領域

## 5. 収納容量データ

クローゼット、本棚、収納ケースなどの内寸と収納物を記録する。

旧居の収納量と新居の収納容量を比較し、追加収納が必要かを判断する。

## 6. 新居データセット

新居では次のデータをそろえると再利用性が高い。

- 公式間取り図
- Polycam などの3Dスキャン
- 室内写真・動画
- 壁、窓、ドア、天井高などの実測値
- 冷蔵庫置場、洗濯機パン、収納内部寸法
- コンセント、LAN、TV、スイッチ位置
- 搬入経路寸法
- 管理規約、ゴミ出し、工事・搬入ルール

## 7. 旧居と新居の自動比較

理想形は、旧居と新居を同じJSON/YAML形式で表現し、次のような処理を行うこと。

1. 旧居家具を台帳化
2. 新居の3Dスキャンを取得
3. 家具ごとに配置可能領域を探索
4. 搬入経路を確認
5. 電源・ネットワーク条件を加味
6. 複数の家具配置案を生成
7. Before / After を2D・3Dで可視化

## 8. 今後作るとよい成果物

- `furniture-inventory.csv`
- `appliance-inventory.csv`
- `outlets-and-network.yaml`
- `moving-clearance.yaml`
- `storage-capacity.yaml`
- `new-home-scan.glb`
- 旧居/新居比較レポート
- 家具配置案 A/B/C

## 精度に関する注意

3Dスキャンは計画・比較には有用だが、家具購入、カーテン、冷蔵庫、洗濯機、搬入可否などで数cmの差が重要な場合は、必ず実測値を優先する。
