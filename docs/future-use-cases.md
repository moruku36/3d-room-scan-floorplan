# この3Dデータを引っ越しや新居探しにどう使えるか

今回の検証では、現在の部屋を3Dで記録し、そのデータと写真から「部屋の形」「家具の位置」「おおよその寸法」を整理しました。

同じ方法を新居でも使うと、引っ越し前にかなり多くのことを確認できます。

## 1. 今ある家具が新居に置けるか確認する

ベッド、机、本棚、冷蔵庫などについて、今の家でサイズを記録しておけば、新居の部屋サイズと比べられます。

たとえば、

- ベッドを置いても通路が残るか
- デスクと椅子を置いて在宅勤務できるか
- 本棚を置いてもドアやクローゼットが開くか
- 家具を置いた後に部屋が狭くなりすぎないか

といったことを入居前に確認できます。

## 2. 家具配置を何パターンか比較する

新居の3Dデータがあれば、同じ家具を使って複数のレイアウト案を作れます。

たとえば、

- 仕事スペースを広くする案
- 収納を優先する案
- 部屋を広く見せる案
- ロボット掃除機が動きやすい案

などを並べて比較できます。

## 3. 大型家具や家電を搬入できるか確認する

家具が部屋に置けても、玄関や廊下を通れなければ搬入できません。

そのため、新居では次の場所も測っておくと便利です。

- 玄関ドアの幅
- 廊下の幅
- 部屋のドアの幅
- 曲がり角の広さ
- エレベーターの入口幅
- エレベーター内部の大きさ

これらと家具の大きさを比べることで、搬入できる可能性を事前に確認できます。

## 4. コンセントやWi-Fiの位置まで含めて部屋を考える

家具配置だけでなく、次の場所も記録すると実生活に近い検討ができます。

- コンセント
- LAN端子
- TV端子
- Wi-Fiルーターを置けそうな場所
- エアコン
- 照明
- スイッチ

たとえば「机は置けるけれど、近くにコンセントがない」といった問題も入居前に気づきやすくなります。

## 5. 収納が足りるか比べる

今使っている本棚、収納ケース、クローゼットなどの大きさを記録しておけば、新居の収納量と比較できます。

これによって、

- 今の荷物が新居に収まるか
- 追加の棚が必要か
- 引っ越し前に処分した方がよい物があるか

を判断しやすくなります。

## 6. 引っ越し前後で同じ形式の記録を残す

旧居と新居を同じ方法で記録すると、比較がしやすくなります。

### 旧居で残しておくもの

- 3Dスキャン
- 室内写真
- 家具・家電のサイズ
- 収納量
- 持っていく物 / 処分する物

### 新居で集めるもの

- 公式の間取り図
- 3Dスキャン
- 室内写真・動画
- 壁、窓、ドア、天井高などの実測値
- 冷蔵庫置場、洗濯機置場、収納内部の寸法
- コンセント、LAN、TV端子、スイッチの位置
- 玄関・廊下・エレベーターなどの搬入経路

## 7. ロボット掃除機や日常の動線も確認する

家具の位置が分かれば、床の空いている場所や通路も確認できます。

そのため、

- 人が通りやすいか
- 椅子を後ろに引けるか
- ベッドの横を歩けるか
- ロボット掃除機が家具の間を通れるか
- 床置きの物を減らした方がよい場所はどこか

といった、入居後の暮らしやすさも検討できます。

## 8. 将来的に作ると便利な一覧

今後は次のような一覧を作っておくと、新居との比較がさらにしやすくなります。

- 家具一覧：名前、幅、奥行、高さ、重さ、分解できるか
- 家電一覧：サイズ、設置条件、必要なコンセント
- 収納一覧：収納家具やクローゼットの大きさ
- 搬入経路一覧：玄関、廊下、ドア、エレベーターの寸法
- 設備位置一覧：コンセント、LAN、TV、スイッチなど

このリポジトリでは、こうした情報を将来的にAIで比較しやすい形に整理していくことを想定しています。

## 注意点

3Dスキャンは、部屋全体を把握したり家具配置を考えたりするには非常に便利ですが、測量用の機器ほどの精度はありません。

家具や家電を購入するとき、搬入できるかを最終判断するとき、カーテンや収納家具を注文するときなどは、必ず実際にメジャーやレーザー距離計で測った値を優先します。
