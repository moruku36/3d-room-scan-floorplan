# 内見チェックリスト

家2の内見で「あとから測り直せない情報」を漏れなく持ち帰るためのリスト。結果は `homes/home2/` の各ファイルに入れます。

## 持ち物
- スマホ（Polycam、充電・空き容量確認）／モバイルバッテリー
- メジャー（5m以上）、レーザー距離計があれば
- 養生テープ・付箋（写真に寸法を写し込む用）
- 家1の `measurements.yaml` と家具候補一覧（見比べる用）
- コンセント検電器・スマホのスピードテストアプリ（あれば）

## 撮る・スキャンするもの
1. 各部屋を Polycam でスキャン（許可を取る。空室が理想）
2. 各壁を正面から1枚ずつ（コンセント・スイッチ・TV/LAN端子が見えるように）
3. 窓（外の景色・隣棟との距離）、ベランダ、エアコン位置
4. 収納内部（棚・パイプ位置が分かるよう寸法をメジャーと一緒に）
5. 洗濯機置場（防水パン・蛇口高さ・排水口位置）／冷蔵庫置場／キッチン
6. 玄関〜部屋までの搬入経路（ドア幅・廊下・曲がり角・エレベーター内寸）
7. 分電盤（ブレーカー容量）、インターホン、給湯器、ポスト、ゴミ置場、駐輪場

## 測る値（優先度順）
1. 搬入経路：玄関ドア幅、廊下幅、曲がり角、エレベーター扉幅・内寸
2. 家具を置く壁の幅（ソファ幅190cm、ダイニングテーブル120cm など）
3. 洗濯機・冷蔵庫置場の幅・奥行・高さ
4. 窓の幅・高さ・床からの高さ、カーテンレール
5. 天井高、梁・段差・ドア開閉範囲
6. 収納の内寸

## 家1と比べるためのメモ
- 電子ピアノ・ベッド・デスク・本棚（家1の家具）を置く壁はあるか
- 在宅勤務の場所：コンセント数、LAN、Wi-Fi、電波、日当たり・画面の映り込み
- 楽器の音出し可否（規約）、上下左右の生活音
- 収納量：家1のクローゼット/棚と比べて増減は？

## 現地で確認する質問（不動産会社・管理会社）
- 引越し可能日、搬入時間帯・エレベーター養生の有無
- インターネット回線（光の引込、対応事業者、工事の要否）
- 楽器・ペット・ロボット掃除機などの規約
- 原状回復、退去時費用、更新料、管理費の内訳
- 過去の水回りトラブル・騒音の苦情の有無

## 帰宅後にやること
1. 写真を `homes/home2/photos/` に、スキャンを `homes/home2/data/room-scan.glb` に保存
2. `viewing-measurements.yaml` / `delivery-route.yaml` / `property.yaml` を埋める
3. 家具候補の `checks`（搬入・サイズ・動線）を実測値で判定
4. 間取り図とレイアウト案を `homes/home2/outputs/` に作成
