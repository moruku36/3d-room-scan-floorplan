# Room Digital Twin / Moving Data Validation

2026-09-13 に実施した、**Polycam の3Dスキャン + ChatGPT による部屋解析**の検証結果をまとめたリポジトリです。

目的は、現在の部屋をデジタル化し、将来の引っ越し・新居内見・家具配置・搬入可否・ネットワーク/設備設計などに再利用できるかを確認することです。

> **Privacy note:** このリポジトリは public です。`data/room-scan.glb` には実在する室内の3D形状が含まれます。

## Artifacts

| Path | 内容 |
|---|---|
| `data/room-scan.glb` | Polycam からエクスポートした元の3D室内スキャン |
| `outputs/current-room-overview.png` | 写真から作成した現在の部屋の概略間取り図 |
| `outputs/dimensioned-floorplan.png` | GLB座標・寸法を基に作成した寸法付き間取り図 |

| `docs/future-use-cases.md` | 引っ越し・新居検討で今後できること |

## 今回確認できたこと

1. Polycam の GLB から、壁・床・窓・ドア・家具などの位置や外接寸法を取り出せる。
2. 写真を併用することで、3Dデータだけでは判別しづらい家具や用途を補完できる。
3. GLB の座標から、概略ではなく縮尺を持った2D間取り図を生成できる。
4. 家具寸法と新居側の寸法を同じ形式で持てば、家具配置や搬入可否の比較に利用できる。

## 精度上の注意

このリポジトリの寸法は **Polycam スキャンの座標や物体バウンディングボックスから推定した値**です。建築図面・レーザー距離計による実測値ではありません。

家具購入、搬入可否、カーテン、家電設置などで数cmの差が問題になる場合は、必ず実測値で再確認してください。
